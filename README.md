# Кафе «Антейку» — сайт

Официальный сайт кафе «Антейку». Здесь гости могут узнать всё о кафе, посмотреть меню, заказать доставку и забронировать столик онлайн.

## О проекте

Сайт помогает гостям быстро найти нужную информацию и сделать заказ, не звоня по телефону. Основные задачи:

- рассказать о кафе, его атмосфере и истории;
- показать меню с ценами и фотографиями блюд;
- принимать заказы на доставку;
- принимать бронирование столиков;
- дать контакты, адрес и часы работы.

## Основные разделы

### Главная
Приветствие, фото интерьера и блюд, быстрые кнопки «Заказать доставку» и «Забронировать столик», акции и новости.

### Меню
Категории блюд (завтраки, горячее, салаты, десерты, напитки и т. д.), описание, вес и цена каждой позиции, фотографии, отметки о популярных блюдах и новинках.

### Доставка
- оформление заказа прямо на сайте;
- выбор блюд и количества, корзина;
- указание адреса, времени и способа оплаты;
- информация о зонах доставки, стоимости и минимальной сумме заказа;
- контактный телефон для уточнения заказа.

### Бронирование столика
Форма бронирования:
- имя и номер телефона;
- дата и время;
- количество гостей;
- пожелания (у окна, детский стул, праздник и т. д.).

После отправки заявки администратор связывается с гостем для подтверждения.

### О нас
История кафе, команда, концепция, фотографии зала и кухни.

### Контакты
Адрес, карта проезда, телефон, соцсети, часы работы.

### Прочая информация
Акции и скидки, отзывы гостей, галерея, вопросы и ответы (FAQ), условия доставки и бронирования.

## Запуск

1. Скачайте или клонируйте проект:
   ```bash
   git clone <ссылка-на-репозиторий>
   cd anteika
   ```
2. Откройте `index.html` в браузере или запустите локальный сервер:
   ```bash
   npx serve .
   ```
3. Перейдите по адресу `http://localhost:3000`.
